# Sales Performance Dashboard

Interactive Power BI dashboard analyzing sales performance, revenue trends, KPIs, and business insights.

---

## Overview

This project focuses on analyzing company sales data to identify revenue trends, top-performing products, regional performance, and key business KPIs using Power BI and Excel.

The dashboard helps businesses make data-driven decisions by converting raw sales data into meaningful visual insights.

---

## Tools Used

- Power BI
- Excel
- SQL
- Data Visualization

---

## Objectives

- Analyze monthly and yearly sales trends
- Track important business KPIs
- Identify top-performing products and regions
- Monitor revenue and profitability
- Create an interactive dashboard for business reporting

---

## Key Features

- Interactive Power BI Dashboard
- KPI Cards for Revenue, Profit, and Orders
- Sales Trend Analysis
- Regional Performance Visualization
- Product Category Insights
- Dynamic Filters and Slicers

---

## Key Insights

- Identified highest revenue-generating product categories
- Analyzed monthly sales growth trends
- Compared regional sales performance
- Evaluated profit contribution by products

## Dashboard KPIs

- Total Orders

## Business Impact

This dashboard improves reporting efficiency and helps stakeholders make informed business decisions using real-time sales insights.
